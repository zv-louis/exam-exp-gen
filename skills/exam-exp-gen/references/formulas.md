# 数式・記号の書き方

問題文と解説の数式は、**原本の記号と記法を忠実に再現する。**
読みやすさのために、記号を ASCII の代用品に置き換えない。

## 原則

- 原本に書かれた記号・添字・単位・分数の形をそのまま写す。
- 読み取れない記号は、推測せずユーザーに確認する。
- 解説で出す式も、問題文と同じ記法にそろえる。

## 段階ごとの書き方

式の複雑さで、書き方を選ぶ。

### 1. Unicode の文字で書く（単純な式）

四則演算、比較、上付き・下付きが 1 段で済む式は、markdown の本文にそのまま書く。

| 原本の記号 | 書き方 | 使ってはいけない代用 |
|---|---|---|
| かけ算・わり算 | `×`　`÷` | `x`　`*`　`/`（÷ の代用） |
| マイナス | `−`（U+2212） | `-`（ハイフン） |
| 約等号・不等号 | `≒`　`≠`　`≦`　`≧`　`＜`　`＞` | `~=`　`<=`　`>=` |
| 理由・結論 | `∵`　`∴` | `because`　`so` |
| 角度・温度 | `°`　`℃` | `度`　`C` |
| 上付き | `m²`　`m³`　`10⁻³` | `m^2`　`m3` |
| 下付き（化学式・添字） | `H₂O`　`CO₂`　`a₁` | `H2O`　`CO2`　`a1` |
| 矢印・反応式 | `→`　`⇄`　`↑`　`↓` | `->`　`<=>` |
| ルート | `√2` | `sqrt(2)` |
| パーセント | 原本に合わせて `％` または `%` | |

- 単位は原本の表記に合わせる（`g/m³`、`m/s` など）。
- Unicode にない上付き・下付き（例：`xⁿ⁺¹` の一部の文字）が出てきたら、段階 2 にする。

### 2. `$$ ... $$` で書く（組版が要る式）

次のいずれかを含む式は、Unicode では崩れる。`$$ ... $$` で書く。
ODT に変換するとき、`scripts/md2odt.py` が自動で画像にして埋め込む。

- 縦に組む分数（分子・分母が式になっているもの）
- ルートの中に式が入るもの、多重の根号
- 総和・積分・極限、行列、連立方程式
- 上付き・下付きが入れ子になったもの
- 記号の上下に付く記号（ベクトルの矢印、ハット、バーなど）

罫線文字や空白で組んだ疑似的な分数（コードブロックの中に `───` で書く形）は使わない。

```markdown
$$
湿度〔％〕 ＝ \dfrac{7.3\ \mathrm{g/m^3}}{15.4\ \mathrm{g/m^3}} \times 100 \fallingdotseq 47
$$
```

#### 書き方の決まり

- `$$` は **行頭** に置く。1 行で `$$ x = 1 $$` と書いてもよい。段落の途中には置けない。
- 式は LaTeX 風に書く。単位などの立体は `\mathrm{...}` で囲む。
- **日本語は `$$` の中に直接書く。** `\text{...}` や `\mathrm{...}` の中に入れない（字形が出ない）。
  日本語の部分は本文と同じフォントで、それ以外は式の字体で、同じ基準線に並べて描かれる。
- 行を分けたいときは `\\`（バックスラッシュ 2 つ）で区切る。行ごとに中央に並ぶ。`=` の位置はそろわない。
- 等式を何行も並べる途中式は、`$$ ... \\ ... $$` で書く。markdown の本文に 1 行ずつ書くと、1 行につながってしまう。
- 引用ブロック（`>`）や箇条書きの中の `$$` は変換されない。式は、ブロックの外に出して書く。
- 文の途中に入れる式（インライン）には使えない。`$...$` は変換されない。短い式は段階 1 の Unicode で書く。
- 使えない記法がある（`align` などの環境、一部のコマンド）。変換がエラーで止まったら、式を分けるか、別の書き方にする。
  字形のない文字が混じったときも、黙って通さずエラーで止まる。
- 通常の markdown のプレビュー（VS Code など）でも、`$$` は式として表示される。ただし日本語が混ざる式は、プレビューと ODT で見た目が少し違う。

#### 変換後の確認

- ODT を PDF にして画像で見る（[odt-export.md](odt-export.md)）。確認する点：
  - 原本の式と、記号・添字・数値が一致しているか
  - 欠け、はみ出し、字形の違いがないか
- 本文では、式の前後に式の意味を文で書く。式の画像だけに任せない（読み上げや検索で消えるため）。
- 式が用紙幅を超えるときは自動で縮小される。縮みすぎるなら、式を `\\` で分ける。

#### 仕組み（調整するとき）

- `scripts/md2odt.py` の `extract_formulas`、`render_formula`、`embed_formulas`。
- 描画は matplotlib の mathtext。LaTeX 本体は要らない。大きさは `EQ_FONT_PT`、解像度は `EQ_DPI`。
- 画像は変換のたびに作り、ファイルとしては残さない。

#### 画像を単独で作りたいとき

図の中に式を入れるときは、figkit の図に `$...$` で書く（字体は `$$` の数式と同じ）。
式だけの画像が別に要るときも、図と同じく `intermediates/figs/` にスクリプトを置いて作る（[figures.md](figures.md)）。

```python
# intermediates/figs/a5_eq_quadratic.py
import figkit as fk

fig, ax = fk.canvas((0, 6), (0, 1))
ax.text(3, 0.5, r"$x=\dfrac{-b\pm\sqrt{b^2-4ac}}{2a}$", fontsize=14, ha="center", va="center")
fk.save(fig, __file__)
```

- ファイル名は `a<番号>_eq_<内容>.py`（画像は `a<番号>_eq_<内容>.png`）。
- 日本語は `$...$` の外に書く。日本語を混ぜた式は、`render_formula` の分け方（日本語と式を別々に描く）に従う。
