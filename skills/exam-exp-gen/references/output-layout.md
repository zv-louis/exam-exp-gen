# 成果物のレイアウト

## ディレクトリ

試験ごとにディレクトリを作る。名前は `YYYYMMDD` か `YYYYMMDD_<学校名など>`。

```
<試験ディレクトリ>/
├── <原本>.pdf            # スキャン PDF（入力）
├── solutions.odt         # 解説のアウトプット（任意）。全大問の解説を 1 つにまとめたもの
└── intermediates/        # 作成途中のファイル
    ├── q<番号>.md          # 問題の書き起こし
    ├── a<番号>.md          # 解説
    ├── figs/               # 図を作るスクリプト（1 つの図に 1 つ。figures.md）
    │   ├── q<番号>_fig_*.py
    │   └── a<番号>_fig_*.py
    └── images/             # 画像類
        ├── page-<N>.png        # PDF のページ画像
        ├── q<番号>_fig_*.png   # 問題に載っている図（切り出し）
        └── a<番号>_fig_*.png   # 解説用に作った図
```

- 番号は大問の番号。例：問題 5 なら `intermediates/q5.md`、`intermediates/a5.md`。
- 作成途中の md と画像は、`intermediates/` 以下に置く。md は `intermediates/` 直下、画像は `intermediates/images/`。
- 解説のアウトプット（`solutions.odt`）は、試験ディレクトリ直下に置く。`intermediates/` には出さない。
- `intermediates/` と `intermediates/images/` は、スクリプトが自動で作る。`figs/` は、図のスクリプトを書くときに作る。
- 図の PNG は、`figs/` にある同じ名前のスクリプトから作られる。PNG だけを手で直さない。
- md と画像は同じ `intermediates/` 以下にあるので、md からは `images/…` と書いて参照する。
- 試験ディレクトリは、プロジェクトのルート直下に置く。

## q*.md の書式

```markdown
# 問題 5

<導入文>

## 実験

- ㋐ …

### 図

![図の説明](images/q5_fig_cup.png)

### 表

| … |

## Q.1

<設問文>
```

- 大見出しは `# 問題 <番号>`、設問は `## Q.<n>`。
  原本の設問が `(1)`、`(2)` の形なら、見出しも `## (1)`、`## (2)` と原本に合わせる。小問の ①② は本文に書く。
- 原本の斜体の文字（*n*、*x* など）は、`*n*` のように斜体で写す。
- 選択肢は箇条書きで、`ア　…` の形に書く。
- 原本で取り消されている設問は `~~…~~` で残す。
- 読み取りに迷った箇所は、本文に書かず、ユーザーに確認する。
